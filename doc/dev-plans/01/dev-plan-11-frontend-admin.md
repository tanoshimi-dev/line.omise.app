# Step 11 — 管理画面（コンテンツ作成・更新、Admin 限定）

**フェーズ:** Phase 1 — Frontend
**依存:** Step 07（Next.js 基盤）, Step 05〜06（コンテンツ/試験 API）

---

## ゴール

Admin ロールのユーザーのみがアクセスできる管理画面を実装し、講座・レッスン・記事・
事例・試験問題を作成・更新できるようにする。

---

## タスク

### 11.1 アクセス制御

- [ ] `/admin` 配下は `role = admin` でないユーザーをリダイレクト（未ログインはログインへ、
  Reader はトップページ等へ）
- [ ] `GET /auth/me` の `role` をサーバーコンポーネント側で確認する仕組みを実装

### 11.2 講座・レッスン管理

- [ ] 講座一覧・作成・編集フォーム（`/admin/courses`）
- [ ] レッスン一覧・作成・編集フォーム（Markdown エディタ、シンプルな textarea でも可、
  リッチエディタは任意）
- [ ] 公開/下書き（`status`）の切り替え UI

### 11.3 記事管理

- [ ] `line-operation` / `ai` 記事の一覧・作成・編集フォーム（`/admin/articles`）
- [ ] タグ付け UI

### 11.4 事例管理

- [ ] 導入事例の一覧・作成・編集フォーム（`/admin/usecases`）

### 11.5 試験管理

- [ ] レッスンに紐づく試験・設問・選択肢の作成/編集 UI（`/admin/lessons/{id}/exam`）

---

## 成果物

- `src/app/admin/` 配下の管理画面一式
- Admin 用フォームコンポーネント（講座/レッスン/記事/事例/試験、共通化できる部分は共通コンポーネント化）

## 完了条件

- Admin ユーザーが講座・レッスン・記事・事例・試験を作成・編集・削除できる
- Reader / 未ログインユーザーは `/admin` にアクセスできない
- 下書き（draft）コンテンツが公開ページに表示されないことを確認できる
