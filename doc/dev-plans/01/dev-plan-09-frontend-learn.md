# Step 09 — `/learn/` 講座・記事一覧/詳細・試験・進捗表示 UI

**フェーズ:** Phase 1 — Frontend
**依存:** Step 07（Next.js 基盤）, Step 05〜06（コンテンツ/試験/進捗 API）

---

## ゴール

README で決定済みの URL 構成に沿って `/learn/` 配下を実装する。

```
/learn/                          学習コンテンツ トップ
/learn/line-marketing/           LINEマーケティング講座（コース形式）
/learn/line-marketing/{lesson}/  各レッスン
/learn/line-operation/           LINE運用・設定（記事形式）
/learn/line-operation/{article}/ 各記事
/learn/ai/                       生成AI活用事例（記事形式）
/learn/ai/{article}/             各記事
```

---

## タスク

### 9.1 `/learn/` トップ

- [ ] 3カテゴリ（マーケティング講座 / 運用・設定 / AI活用事例）への導線を持つ一覧ページ
- [ ] README で保留中の「ハンバーガーメニュー内の並び順」をこのステップで確定する

### 9.2 講座（コース形式） — `/learn/line-marketing/`

- [ ] 講座トップ: レッスン一覧（順序立て、ログインユーザーは完了状況をバッジ表示）
- [ ] レッスン詳細ページ: 本文表示（Markdown レンダリング）、前後レッスンへのナビゲーション
- [ ] レッスン末尾に試験（exam）がある場合は受験導線を表示
- [ ] 試験受験 UI: 設問・選択肢表示 → 送信 → 結果（スコア・合否）表示
- [ ] 未ログイン時: 閲覧は可能、進捗保存・試験受験はログインを促す（ログインへのリダイレクト or モーダル）

### 9.3 記事一覧形式 — `/learn/line-operation/`, `/learn/ai/`

- [ ] 記事一覧ページ（`/learn/line-operation/`）: タグ絞り込み UI
  （`?tag=rich-menu` クエリ方式を採用 — README の推奨に従う）
- [ ] 記事詳細ページ（`/learn/line-operation/{slug}/`）
- [ ] `/learn/ai/` も同一コンポーネントを再利用（カテゴリのみ切り替え）

### 9.4 進捗表示

- [ ] ログインユーザー向けに「マイページ」的な進捗サマリーを表示する場所を決定
  （ヘッダーのユーザーメニューからアクセスできる `/learn/me` 等）
- [ ] `GET /api/me/progress` を使って講座ごとの完了率を表示

### 9.5 SEO

- [ ] 各記事・レッスンページに `generateMetadata` で title/description を設定
- [ ] `app/sitemap.ts` で `/learn/` 配下の公開ページを動的にサイトマップへ含める

---

## 成果物

- `src/app/learn/` 配下のページ一式（トップ・講座・記事・進捗）
- 試験受験・結果表示コンポーネント
- タグ絞り込み UI

## 完了条件

- 講座・記事の一覧/詳細がコンテンツ API から取得して表示される
- ログインユーザーがレッスンを完了しマークでき、進捗が反映される
- 試験を受験し結果が表示される
- 未ログインでも記事・レッスンの閲覧はできる
