# Step 2-4 — フロントエンド: クイズ（練習）・検定 受験 UI

**フェーズ:** Phase 2 — クイズ・検定機能
**依存:** Step 2-3（解答・採点 API）、Phase 1 [dev-plan-09-frontend-learn.md](../01/dev-plan-09-frontend-learn.md)

---

## ゴール

`/learn/quiz/` 配下（配置は 2-4.1 で決定）に、練習モードのクイズと検定モードの試験、
それぞれの受験 UI を実装する。

---

## タスク

### 2-4.1 配置の決定

- [ ] クイズ／検定を `/learn/` 配下に置くか、独立セクション（例: `/quiz/`, `/exam/`）にするかを決定する
- [ ] クイズ一覧ページ（`practice`/`exam` を区別して表示、例: 「クイズ」「検定」のタブ or セクション分け）

### 2-4.2 練習モード UI

- [ ] `QuizQuestionCard` コンポーネント
  - 問題文 → 選択肢（単一=ラジオ／複数=チェックボックス）→ 解答ボタン
  - 解答後: 正誤表示（正解/不正解の視覚的フィードバック）＋ 解説 ＋ 参考リンク ＋ 「次の問題へ」
- [ ] `/learn/quiz/:slug` 受験ページ（`mode = practice` の場合）

### 2-4.3 検定モード UI

- [ ] `ExamRunner` コンポーネント
  - 全設問を順に解答（正誤・解説はまだ見せない）、進捗表示（例:「3/10問」）
  - 最終設問で「提出」操作 → 確認ダイアログ（未回答がある場合の警告、2-3.3 の仕様に合わせる）
- [ ] 結果画面
  - 最終スコア（正答数／正答率）、`passing_score` 設定時は合否表示
  - 設問ごとの正誤・正しい選択肢・解説を振り返れる一覧
- [ ] `/learn/quiz/:slug`（または決定した URL 体系）で `mode = exam` の場合、上記 UI に出し分け

### 2-4.4 未ログイン時の扱い

- [ ] 練習モード・検定モードともに未ログインで解答・受験は可能（結果はその場で表示）
- [ ] 未ログイン時は「ログインすると受験履歴・進捗が保存されます」等の導線を結果画面に表示

---

## 成果物

- `src/components/quiz/QuizQuestionCard.tsx`
- `src/components/quiz/ExamRunner.tsx`
- `/learn/quiz/[slug]` ページ（または決定した URL 配下）

## 完了条件

- 練習モードのクイズに未ログインで解答し、その場で正誤・解説が確認できる
- 検定モードの試験に全問解答して提出すると、最終スコア（・合否）と設問ごとの振り返りが表示される
- 未ログイン時にログイン導線が適切に表示される
