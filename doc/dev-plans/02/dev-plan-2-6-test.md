## タスク

### 2-6.1 Go テスト

- [ ] Admin CRUD のバリデーション（選択肢不足、正解フラグなし、`allow_multiple=false` での複数正解、`mode` に応じた `passing_score` 制御）
- [ ] 練習モード採点ロジック（単一選択・複数選択、正誤判定）
- [ ] 検定モード採点ロジック（一括採点、`score`/`passed` 算出、未回答設問の扱い）
- [ ] 認可: 他ユーザーの履歴・進捗・受験詳細にアクセスできないこと
- [ ] 正解フラグ・解説が解答前／提出前のレスポンスに含まれないこと

### 2-6.2 Next.js（Vitest）

- [ ] `QuizQuestionCard` の解答・正誤表示・解説表示
- [ ] `ExamRunner` の進捗表示・未回答警告・提出後の結果表示
- [ ] マイページの履歴・進捗コンポーネント（未ログイン時の表示切り替えを含む）

### 2-6.3 Playwright E2E

- [ ] 未ログインで練習モードのクイズに解答し、正誤・解説が表示される
- [ ] ログインして検定モードの試験を最後まで解答・提出し、最終スコア（・合否）が表示される
- [ ] ログイン後、マイページで練習モードの解答履歴・検定モードの受験履歴/進捗が表示される
- [ ] Admin としてクイズ／検定・設問・選択肢を作成し、公開後にフロントエンドから解答できる
